# Romani Music

An archive of Romani music. Romani musicians play in many countries. The music differs from country to country.

Live site: [www.romanimusic.com](https://www.romanimusic.com)

Sister site (living gypsy-jazz circuit): [gypsyjazzhub.com](https://gypsyjazzhub.com)

## What this is

Source for the Romani Music archive. Families, styles, history, sources. Sourced text only.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:8080`.

## Build

```bash
npm run build
```
